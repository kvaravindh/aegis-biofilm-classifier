Overlap settings

Overlap means both species are found within this distance of each other.

A spot counts as overlap when its local B. subtilis share is between this value and 1 minus it.

B. subtilis: local share ≥ 75%
E. coli: local share of B. sub ≤ 25%
Overlap: both present nearby
Unstained background: excluded from all percentages

Training set

Monoculture photos the model learns from. More fields, wells and days make a better model.

  1. Click Add photos under the right species. GitHub opens an upload page for that folder.
  2. Drag in PNG or JPEG photos of pure monoculture wells, taken at the same zoom as your co-culture images. You can drop many at once, up to 100 per upload. Then click Commit changes.
  3. The model retrains automatically. This page updates with the new model a few minutes later.
  4. To take a photo out, click Remove under it and then Commit changes on GitHub. The model retrains without it.
